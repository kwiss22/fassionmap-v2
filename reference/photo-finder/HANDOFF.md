# Claude 인수인계

## 최신 사용자 목표

사진에서 선택한 옷의 **브랜드·제품·실제 판매처**를 찾는 것이 메인입니다. 브랜드를 미리 제한하지 않습니다. 원본을 못 찾았을 때 유사 스타일은 사용자가 선택하는 다음 단계입니다. 알리익스프레스는 대안용으로 검토합니다. 사용자는 네이버 쇼핑 API가 종료되어 제외했다고 명시했습니다. 다시 연결하지 마세요.

비교 기준은 일반 Gemini 웹에 사진을 넣고 “이 옷 판매하는 사이트 찾아줘”라고 했을 때의 정확도·국내 판매 링크·속도입니다. 사용자는 현재 구현이 이 기준에 못 미친다고 판단해 기존 Claude + VS Code 프로젝트로 옮겨 검토하려 합니다.

## 현재 상태와 한계

- 현재 활성 검색은 Gemini REST generateContent 한 번입니다. 분석→검색→JSON 정리의 다중 AI 요청은 제거했습니다. 미리보기는 검색 이후 별도 요청입니다.
- 실상품 Alpha Industries M-65 Heritage 사진 한 장에서 브랜드/모델을 맞힌 사례는 있습니다. 일반 착장·연예인 사진 여러 장에서 정확도를 검증하지 않았습니다.
- 단일 요청 실험에서 약 37초가 걸린 사례가 있습니다. 이전의 7초대 응답은 옛 다중 단계 버전의 중간 분석 결과였고, 현재 속도 보장이 아닙니다.
- Gemini 웹과 API가 같은 모델·검색 경로라고 확인하지 못했습니다. 웹 화면의 모델 이름을 API 모델 ID로 추정하지 마세요.
- 이름을 맞혀도 URL은 틀릴 수 있습니다. 실제 조회에서 403/404가 있었고, 사용자가 Gemini 웹보다 결과와 편의성이 떨어진다고 지적했습니다.
- Markdown 제목·링크 추출은 불완전합니다. 원문 rawResponse 및 grounding 출처와 화면의 정보를 비교하세요.
- 강제 JSON 실험에서 grounding 출처가 비어 나온 적이 있어 현재는 자연어 원문을 보존합니다. 한 번의 실험을 API의 일반 제약으로 단정하지 마세요.
- 미리보기는 제한된 판매처 허용 목록과 OG 메타태그에 의존합니다. 403은 상품 미존재로 단정하지 않으며, 404/410일 때 구매 링크를 비활성화합니다.
- 직접 이미지 비교는 현재 활성 검색에 없습니다. 검색 출처가 있다고 동일 제품·정품·재고가 검증된 것이 아닙니다.
- 예시 착장 3개는 AI 생성 데모입니다. 실제 성공 사례가 아닙니다.
- Ali API 자격증명과 제휴 승인은 이 내보내기에 없습니다. 루트 Next.js 쪽의 기존 연동과 구분하세요.
- 요청 제한은 Worker 메모리에 있어 공개 서비스의 완전한 비용 통제가 아닙니다. 업로드 원본을 서버에 영구 저장하지 않습니다.

## 다음 작업

1. 기존 Gemini provider·모델·프롬프트를 확인하세요. 이 폴더를 전체 덮어쓰거나 자동 통합하지 마세요.
2. 사진+짧은 요청의 API 원문, 출처, 응답 시간, 화면 추출 결과를 나란히 확인하는 진단부터 만드세요. 키·사진 원본을 로그에 남기지 마세요.
3. 같은 사진·질문으로 Gemini 웹과 비교하세요. 제품 정답, 상세 링크 유효성, 국내 판매처, 응답 시간을 기록하세요.
4. 원문은 좋은데 화면에서 사라지는 경우와 API 자체가 못 찾는 경우를 분리하세요. 이미지가 없으면 큰 빈 카드를 만들지 말고 제품명·판매처부터 보여주세요.
5. 품질 확인 후 필요한 부분만 기존 Next.js 구조에 옮기세요. 유사 추천은 사용자 요청 시만 제공하고 가짜 가격·재고·정확도를 추가하지 마세요.

## 기존 문서와 충돌

루트 AGENTS.md/PRD에는 학습용·상황별 코디·사진 분석 제외·네이버 필수 통과 등 이전 기획이 남아 있습니다. 최신 사용자 지시는 사진 기반 서비스와 네이버 제외입니다. 이 폴더는 비교용 스냅샷으로 기존 실행 앱을 바꾸지 않았습니다. 실제 통합 전에 최신 지시에 맞게 계획 문서를 정리해야 합니다.

## 검증 범위

Node 테스트와 Worker 빌드가 통과한 스냅샷입니다. 테스트는 호출 횟수·입력·링크·오류·미리보기 분리 등을 검사할 뿐 검색 정확도를 보장하지 않습니다. 관리형 브라우저 도구가 없어 실제 390/768/1024/1440px 시각 QA와 스크린샷 검증은 완료하지 못했습니다.

## 그대로 전달할 요청

> 이 폴더는 별도 환경에서 만든 사진 검색 참조 코드다. 전체를 합치지 말고 검색 품질을 떨어뜨리는 부분부터 검토해 줘. 사진+짧은 요청을 Gemini에 한 번 보내고, 원문과 화면 결과를 대조해 줘. 네이버는 제외하고 알리는 원본을 못 찾았을 때 사용자가 선택하는 대안에만 써. 일반 Gemini 웹보다 유용한 제품명과 실제 판매 링크가 나오는지 먼저 검증해 줘.
