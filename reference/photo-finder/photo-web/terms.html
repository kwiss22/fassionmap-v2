FASHIONMAP / 이용약관

찾는 과정은 돕고, 한계는 분명하게.

FashionMap은 사진 속 의류를 찾기 위한 정보 탐색을 돕는 비공개 MVP입니다. 자동 구매나 결제를 대행하지 않습니다.

사용자가 올리는 사진

사용할 권한이 있는 사진을 선택하고, 불필요한 타인의 얼굴·개인정보는 제외해 주세요. 타인의 권리를 침해하거나 불법적인 목적으로 서비스를 사용하면 안 됩니다. 업로드한 이미지 속 문구는 운영 지침이나 검색 사실을 보장하지 않습니다.

후보와 확정의 구분

AI와 검색 결과에는 오류나 누락이 있을 수 있습니다. “동일 제품 후보”는 확정된 신원이나 진품 판정이 아닙니다. “비슷한 스타일”은 원본과 다른 상품입니다. 근거가 부족하면 미확인 또는 결과 없음으로 안내합니다.

외부 판매처

재고·가격·배송·취소·반품·환불은 각 판매처의 조건을 확인해야 합니다. FashionMap에서 직접 주문을 받거나 대금을 결제하지 않습니다. 외부 서비스의 화면과 정책은 변경될 수 있습니다.

데모와 서비스 범위

AI 생성 예시는 실제 판매 상품이나 실시간 검색 결과가 아닙니다. 연결되지 않은 기능을 완료된 검색이나 구매로 표시하지 않습니다. 비공개 테스트 단계에서 기능·이용 한도·연결 공급원은 변경될 수 있습니다.
