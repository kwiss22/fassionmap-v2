FASHIONMAP / 개인정보 처리 안내

사진은 필요한 영역만.

아래 내용은 현재 FashionMap 비공개 MVP의 동작을 설명합니다. 운영자 정보와 외부 서비스 계약에 따른 세부 처리 조건은 정식 공개 전에 확정해 안내합니다.

어떤 정보를 사용하나요?

사진을 선택하면 브라우저가 이미지를 표시합니다. 검색 버튼을 누를 때 선택한 영역의 JPEG 이미지와 사용자가 적은 선택 정보(이름·행사·날짜 등)가 서버로 전송됩니다. 얼굴이나 불필요한 개인정보가 포함되지 않도록 의류 영역을 좁혀 주세요. 얼굴로 사람을 식별하지 않습니다.

외부 서비스로 전달되는 내용

실제 검색이 설정된 경우 선택 이미지와 검색 단서는 Google Gemini API로 전달되어 의류 특징 분석과 검색을 수행합니다. 외부 API의 처리·보관·국외 이전 조건은 사용 계정과 Google의 적용 약관에 따릅니다. Gemini API 약관을 확인할 수 있습니다.

제휴 상품 검색이 설정된 경우에는 의류 특징을 설명하는 검색어를 연결된 상품 API에 전달합니다. 제휴 상품 API에는 업로드 사진 자체를 보내지 않습니다. 상품 이미지를 비교할 때에는 해당 이미지와 선택 영역을 Gemini API에 전달할 수 있습니다.

보관과 삭제

현재 앱 코드에는 업로드 사진을 파일이나 데이터베이스에 저장하는 기능이 없습니다. 사진은 브라우저 메모리에서 처리하며 페이지를 닫으면 이 메모리 상태가 사라집니다. 이는 Google이나 호스팅 사업자의 처리·보관 정책까지 삭제를 보장한다는 의미는 아닙니다. 검색 이미지나 내용은 앱 로그에 직접 출력하지 않습니다.

외부 링크와 이미지

외부 상품 이미지가 표시되거나 판매 링크를 열면 판매처가 IP 주소 등 통신 정보를 수신할 수 있습니다. 구매·결제·배송 정보는 판매처가 처리합니다. 현재 사이트에는 자체 광고 추적 코드나 이용자 분석 도구를 추가하지 않았습니다. 호스팅 플랫폼의 로그인·접근 처리는 해당 플랫폼 정책에 따릅니다.

문의와 권리 행사

사진 사용이나 처리 관련 문의는 문의 페이지에서 공개된 운영자 채널로 요청할 수 있습니다. 현재 문의 채널이 등록되지 않았다면 정식 서비스가 아닌 MVP 준비 단계입니다.
