# Fashionmap — 서비스 PRD (MVP 출시)

| 항목 | 내용 |
|---|---|
| 버전 | 1.0 |
| 갱신 | 2026-06-11 |
| 목표 | **실제 공개 서비스 출시** |

---

## 1. 한 줄 정의

> **상황·체형·예산을 말하면, AI가 이유(Why)와 함께 입을 룩과 살 만한 상품을 골라주는 에디토리얼 패션 서비스.**

- **시장:** 미국, 영어 UI
- **톤:** 패션 매거진(SSENSE / Matches 류) — 챗봇·쇼핑몰 그리드와 다르게

---

## 2. 왜 만드나

### 사용자 문제

- 쇼핑 검색은 **상품 나열**만 해준다. “나한테 왜 맞는지”가 없다.
- AI 패션 앱은 **대화·환각·저신뢰 상품**이 많다. 실제로 사기 어렵다.

### Fashionmap의 답

| | 일반 쇼핑 검색 | Fashionmap |
|---|---|---|
| 시작 | 키워드 | “비 오는 출근, 5'5, 예산 $200” 같은 **상황** |
| 결과 | 상품 그리드 | **에디터 노트** + **Why가 붙은** 상품 |
| 느낌 | 마켓플레이스 | 매거진을 읽다가 쇼핑 |

---

## 3. 누구를 위한 서비스인가

| | |
|---|---|
| **대상** | 미국, 25–40대, 스마트 캐주얼·에디토리얼 취향 |
| **하는 일** | 출근·데이트·여행·레이어링 등 **상황별** 코디 + 쇼핑 |
| **원하는 것** | “뭘 사지”보다 **“어떻게 입을지”**부터 |
| **비대상** | 최저가 대량 구매, 도매·리셀, 사진으로 옷 분석 |

---

## 4. 핵심 경험 (사용자가 하는 일)

### ① AI 스타일링 (메인)

1. 홈 또는 상단에서 **무엇을 입을지** 입력  
2. AI가 **룩 요약(에디터 노트)** 과 **이유가 달린 상품** 제안  
3. 마음에 들면 상품 보기 → **외부 몰**로 이동해 구매  

**차별점:** 채팅이 아니라 **한 번에 제출 → 읽을 거리 + 쇼핑** 구조. 모든 상품에 **Why**가 보임.

### ② 쇼핑 검색 (보조)

- 키워드·카테고리로 **일반 상품 검색**  
- AI 결과와 **화면 톤을 다르게** — AI는 “읽기”, 쇼핑은 “훑기”

### ③ 홈 — 오늘의 룩 & 에딧

- **AI picks:** AI가 고른 룩 + 슬롯별 이유 (홈에서는 미리 준비된 큐레이션)  
- **브랜드 에딧:** 이번 주 테마 상품 (매거진 호 느낌)

### ④ 저장 & 피드

- 마음에 든 상품 **저장**  
- 브랜드 **팔로우** 후 피드에서 모아보기  
- (v1) 기기 안에만 저장 — 계정 없음

### ⑤ 매거진 호 (VOL)

- “이번 주 이슈” — VOL·시즌·에디토리얼 섹션  
- 주기적으로 **새 호** 발행해 홈·피드 분위기 갱신

---

## 5. MVP에 꼭 들어가는 것

**사용자에게 보이는 것**

- 홈 (AI 입력 + AI 룩 + 브랜드 에딧)
- AI 큐레이션 검색
- 일반 쇼핑 검색
- 상품 상세 · 저장 · 피드 · 브랜드

**출시 품질**

- 클릭해도 안 되는 버튼·가짜 숫자·빈 필터 **없음**
- AI 결과가 일반 검색과 **다른 종류의 화면**으로 느껴짐
- 개인정보·이용약관·제휴 링크 고지

---

## 6. MVP에서 하지 않는 것

| 안 함 | 이유 |
|---|---|
| 채팅형 AI | 범위·비용·차별점 흐림 |
| 사진/옷장 분석 | 비용·신뢰·개인정보 |
| 회원가입·로그인 | v1은 빠른 출시; 저장은 기기 로컬 |
| 앱 스토어 앱 | 웹으로 검증 |
| 결제·장바구니 | 외부 몰 링크만 |
| 광고·유료 구독 | v1은 사용성 검증 우선 |
| 한국어/i18n | v1은 영어(미국)만 |

---

## 7. 수익 (v1)

- 상품 **제휴·어필리에이트 링크** (외부 몰 이동 시)  
- v1에 광고·구독 없음

---

## 8. 성공 기준 (출시 후 30일)

**아래 3개 중 2개 달성**

1. **AI 사용 → 상품 클릭** — AI 큐레이션 쓴 세션의 15% 이상이 상품 1개 이상 클릭  
2. **안정감** — AI 검색이 자주 실패하거나 너무 느리지 않음 (체감 usable)  
3. **다시 옴** — 저장하거나 2번 이상 방문한 사용자 10% 이상  

**반드시:** 망가진 UI·가짜 기능 0건

---

## 9. 브랜드·UI 원칙

- **사진·여백**이 주인공, 테두리·라벨 남발 금지  
- AI는 **색·반짝임**이 아니라 **카피·Why·배치**로 표현  
- 로봇 이모지·채팅 말풍선 톤 지양  
- 에디토리얼 매거진처럼 읽히게

---

## 10. 출시 단계 (제품 관점)

| 단계 | 할 일 |
|---|---|
| **준비** | 가짜·mock 콘텐츠 정리, 법무 페이지, 핵심 화면 QA |
| **공개** | 도메인·소프트 런치, 소수 사용자 피드백 |
| **다음** | 저장 클라우드 동기화, 검색 유입(SEO), 주간 이슈 운영 |

## 11. 나중에 검토할 것 (열린 질문)

- 미국 사용자에게 **K-패션 소스**를 어디까지 노출할지  
- v1 **무계정**이면 재방문이 충분한지 → 언제 로그인 넣을지  
- 브랜드명·도메인 최종  
- 첫 마케팅 채널 (커뮤니티, SNS, SEO 등)
